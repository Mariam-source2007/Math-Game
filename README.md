Math Game

A simple console-based Math Game built in C++ as an OOP practice project.

Features

- Choose the number of questions.
- Choose the difficulty level.
- Choose the type of arithmetic operation.
- Keeps track of the player's score.
- Displays the final result at the end of the game.

Concepts Used

- Object-Oriented Programming (OOP)
- Classes & Objects
- Functions
- Enums
- Structs
- Loops & Conditions
- Random Number Generation

Technologies

- C++
